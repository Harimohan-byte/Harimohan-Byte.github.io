## Privilege Escalation

Then it was not difficult to get into the roots as i already remebered the python command for privilege escalation in this case.

```bash
python3.8 -c ‘import os; os.setuid(0); os.system(“/bin/bash”)’
```
The intresting part of this command is the python version how python 3.8 helps us run this command on linux machines simply as a string .
The Command at first imports os hence giving python the OS enviornment processes,enviornment variables,files,users.

Then The other command setuid(0) is the main thing and the only reason once can escalate to root , since root was run in python 3.8 the linux run this command setting the User Id(uid) to 0 which is the root's uid or else it would have thrown an error on permission dynamics and previlege of the user.

And as we move to root it asks the system to run a shell command which is("/bin/bash").
Hence the python launches bash giving us the root shell.
